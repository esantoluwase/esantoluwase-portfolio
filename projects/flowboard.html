FlowBoard

Category Product • Project Management • Web
Status Functional MVP

Overview

FlowBoard is a lightweight project-management web application designed to help teams organize projects, manage tasks, track progress and visualize workflows.

My Role

Product Lead • Project Supervisor • Web Developer.

I defined the product vision, feature set, workflow, UX direction and technical requirements. DeepSeek/Codex assisted with implementation based on my specifications. I reviewed, tested and refined the implementation.

Development Approach

Idea → Requirements → Specification → AI-Assisted Implementation → Review → Testing → Refinement → Deployment

Key Features

Task creation Task editing Task deletion Priority Assignees Due dates Kanban workflow Drag-and-drop Search Filtering Project progress LocalStorage persistence Responsive interface

Biggest Challenge

Drag-and-drop functionality required careful attention to visual feedback, drop-target highlighting and reliable movement between columns.

Mobile responsiveness was another challenge because the Kanban board needed horizontal scrolling and touch-friendly controls.

What I'm Most Proud Of

The complete task workflow:

Create → Assign → Prioritize → Search → Filter → Move → Edit → Complete

Tasks persist through LocalStorage, allowing users to refresh without losing their current workspace.

Technology

HTML5 CSS3 JavaScript LocalStorage

Future Development

  • Authentication
  • Backend
  • Real-time collaboration
  • Task comments
  • Time tracking
  • Notification center
  • Advanced reporting
  • Project templates
  • Accessibility improvements

Outcome

A functional project management MVP that demonstrates practical product development and project management thinking through a working web application.

What I Learned

Building a practical project management tool requires thinking about real user workflows, not just features. The drag-and-drop interaction and data persistence through LocalStorage were key to making the application feel like a real product rather than a static demo.
